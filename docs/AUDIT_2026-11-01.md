# Audit & repair — 2026-11-01 / 02

A logic audit of Model A (Brian 2) found eight problems. Each was fixed and re-tested.
Three of them change the project's scientific findings. This file records the problem,
the fix, the test and the result for each one. All raw data is in `docs/audit/`.
Regression tests are in `tests/test_audit_fixes.py`; run them with `--slow` to include
the full-circuit equivalence check.

**Headline changes to the science**

1. **The SOM population fired in perfect lockstep in every prior result.** That one
   modelling artefact produced the "coverage, not rate" finding and the 25 Hz seed-44/53
   failures. With realistic (desynchronised) SOM firing:
   - gating depends on the **mean** inhibitory conductance;
   - Yang's ~10 Hz works with modestly stronger synapses;
   - the 25 Hz baseline is 20/20 reliable with the original N = 20 SOM cells.
2. **MD now actually selects the branch.** A new per-branch context circuit does this
   (`model/context_circuit.py`). It is the first test of the core hypothesis in Model A.
3. **Retention comes from input sparsity alone.** The missing control shows that silencing
   the idle input is enough, and inhibition adds nothing to retention. Inhibiting a branch
   whose input stays active *erases* its memory.

## P1. SOM synchrony (the big one)

**Problem.** Every builder started all SOM cells at vRest with an identical bias current
and, at md = 0 / noise = 0, no other input. All 20 cells spiked at the *same instants*
(verified: 280 spikes at 14 distinct times). The "SOM population" was one oscillator
delivering one big GABA volley per cycle.

**Fix.** `som_initial_voltages(..., mode)` in `model/circuit_helpers.py`:
- `random` (new default): each cell starts at a random phase of its own cycle, drawn
  from a dedicated RNG, so Brian's global stream is untouched (tested).
- `sync`: reproduces the legacy behaviour exactly.
- `even`: evenly spaced phases.

**Tests and results** (`experiments/som_async_sweep.py`, `docs/audit/som_async_*.json`):

Reduced circuit, 3 seeds per cell, cell = gated/total:

| SOM rate | 5–12.5 Hz | 15 Hz | 20 Hz | 30 Hz |
|---|---|---|---|---|
| lockstep (legacy) | 0/3 | 0/3 | 0/3 | 3/3 |
| desynchronised | 0/3 | **3/3** | **3/3** | 3/3 |

Mechanism test at 10 Hz (seed 42):

| change | desynchronised | lockstep |
|---|---|---|
| gGABA 6 / 8 / 12 nS | **gates** (ratio 2.5 / 5.7 / 4.8) | fails (1.04 / 1.06 / 1.12) |
| τ_GABA 30 / 40 ms | **gates** (5.7 / 5.6) | fails (1.04 / 1.15) |

Full circuit, 20 seeds (40–59), md = 0:

| condition | gated |
|---|---|
| 25 Hz lockstep | 18/20 (44 and 53 fail, as committed) |
| **25 Hz desynchronised** | **20/20** |
| 30 Hz desynchronised | 20/20 |
| 15 Hz desynchronised | 11/20 (threshold region) |

**What this changes**
- `FINDING_som_rate_divergence.md`: "gating tracks coverage (rate × τ), because calcium
  is event-driven" is a **lockstep artefact**. Under lockstep no conductance increase
  helps, because the gap between volleys is the problem. With desynchronised SOM, gating
  follows the mean inhibitory conductance (∝ N·g·rate·τ), the way a rate model would.
  The remaining gap to Yang's 10 Hz comes from P6: our dendrite is less sensitive to
  shunting than Yang's fit.
- `FINDING_disinhibition_variance.md`: the seed-44/53 failures need lockstep. Low-count
  seeds fail only because all their synapses fire one volley per cycle. With
  desynchronised SOM, N = 20 is 20/20 at 25 Hz, so the 30 Hz lock is no longer needed
  for reliability. The N = 100 rescue was real, but it rescued a lockstep circuit.

## P2. MD never selected a branch

**Problem.** All headline runs used `md_signal_rate = 0`, and SOM was hard-wired to
branch 0. In `full_circuit.py`, MD can only remove branch 0's gate.

**Fix.** `model/context_circuit.py`, with one MD_k → VIP_k → SOM_k → branch k channel per
branch, MD → PV from both channels, and SOM → PV. Context k = MD_k on. Branch-specific
VIP → SOM channels are a stated **modelling assumption**, the same one Model C made.

**Test.** `experiments/demo_v2_zhang2025.py` (rewritten), seed 42:
- Context A: SOM₀ 0.0 Hz, SOM₁ 30.2 Hz; branch 0 → 0.924, branch 1 held at 0.500.
- Context B: SOM₀ 30.0 Hz, SOM₁ 0.0 Hz; branch 1 → 0.925, branch 0 kept at 0.924.

MD selects which branch learns. Retention experiment over 5 seeds: below.

## P3. Forgetting test lacked its control

**Problem.** The "needs BOTH input and inhibition gating" claim was never tested against
"idle input off, *no* inhibition". In the analytical rule, a synapse whose calcium never
crosses θ_d is held exactly, so input-off retention may need no inhibition at all.

**Fix and test.**
- `experiments/retention_md_context.py`: the full 2×2, MD-driven, seeds 42–46
  (`docs/audit/retention_md_context.json`).
- Added an `inputonly` mode to the original `retention_catastrophic_forgetting.py`.

| condition | branch-0 memory after context B (5 seeds) | branch 1 during A |
|---|---|---|
| both (idle input off + inhibition) | 99.9–100% | held at 0.500 |
| **input-only (idle input off, no inhibition)** | **99.9–100%** | held at 0.500 |
| inhibition-only (input on + inhibition) | 32–38% (forgets) | depressed to 0.20–0.28 |
| neither | 100%, but both branches learn everything (no selectivity) | 0.92 |

The original reduced circuit, `inputonly` mode: **99.8% retained**.

**Revised claim.** In this model, protection against forgetting comes **entirely from
input sparsity**. Branch-targeted inhibition does not protect memories. Applied to a
branch whose input is still active, it pushes that branch's calcium into the LTD band and
**erases** it. Inhibition's only demonstrated role is *which* branch learns while an
input is active. Showing a role for MD gating in retention would need overlapping or
shared inputs, which no experiment so far has.

## P4. Ratio metric

**Problem.** The free branch saturates at ρ ≈ 0.924–0.926 on every seed, so the ratio is
effectively 1/ρ_inh. "Gated" branches are actively *depressed* to about 0.2, not held at
0.01. The 0.01–0.02 values were from the retired ODE.

**Fix.**
- `full_circuit` returns `d_rho_inh`, `d_rho_free` and `gated` (r1 > 0.65 AND r0 < 0.5
  AND ratio ≥ 2).
- The reliability sweeps and new scripts use `gated`.

## P5. Scripts silently broken by the plasticity refactor

**Problem.** These scripts ran `net.run` and then read ρ, which is now a held parameter,
so they always reported ρ = 0.5:
- `phase1_single_neuron_gating.py` (the "headline" script)
- `demo_v2_zhang2025.py`
- `sweep_phase_diagram.py` (also a stale circuit: 4 nS coupling, 22 pA, inputs on both
  branches)
- the downstream-plasticity link in `tests/test_postsynaptic_calcium.py`

**Fix.**
- `phase1_single_neuron_gating.py`: now a wrapper on `run_gating_analytical`.
- `demo_v2_zhang2025.py`: now runs on the context circuit.
- `sweep_phase_diagram.py`: now runs on `build_gating_circuit` with analytical
  plasticity, a fresh process per point.
- `tests/test_postsynaptic_calcium.py`: now uses the analytical update on the measured
  calcium trace. Its magnitude threshold had been calibrated to the 346×-too-strong ODE,
  so it now asserts the sign per seed. Its stale per-spike assertion was updated to the
  Eq. 13 leaky-integral semantics. It now passes 16/16.

**Phase diagram result** (5×5, MD 25 Hz, `docs/audit/phase_diagram.json`):
- Plasticity of the SOM-targeted branch depends **only on MD→VIP**.
- At MD→VIP = 0, SOM is at 30 Hz and the branch is gated (ρ 0.34).
- At MD→VIP ≥ 0.31 nS, SOM drops to ≤ 4.6 Hz and the gate opens (ρ 0.92).
- MD→PV changes PV from 0 to 207 Hz with no effect on either branch's ρ.

## P6. V1 was circular

**Problem.** V1 plotted Yang's fitted formula against its own midpoint, so it "matched to
the digit" by construction. The Brian 2 dendrite never uses that formula.

**Fix.** `experiments/v1_dendrite_io_measured.py` measures the actual dendrite. It uses
20 AMPA + NMDA synapses, the soma clamped at rest, 0.8 nS coupling, and tonic g_inh at
Yang's Fig 2c levels. The old panel is relabelled "reference, not a model test".

| g_inh (nS) | g½ measured | g½ Yang | V at g_E ≈ 57 nS: measured / Yang fit |
|---|---|---|---|
| 0 | 19.6 | 22.2 | −6.8 / −9.9 mV |
| 2 | 27.0 | 33.4 | −9.7 / −11.2 mV |
| 10 | 45.3* | 77.8 | **−23.0 / −54.0 mV** |
| 20 | 47.9* | 133.4 | −42.4 / −62.8 mV |
| 35 | 48.2* | 216.8 | −53.0 / −68.4 mV |

\*The curve never saturates within reachable g_E (20 saturating NMDA synapses cap it at
about 57 nS), so the half-point there is not comparable to Yang's.

**Finding.** The model dendrite agrees with Yang without inhibition (mean error 3.3 mV)
but is **much less shunted** by inhibition than Yang's fit (31 mV more depolarised at
10 nS). The same SOM conductance does far less in Model A than in Yang's model. This
explains the rest of the SOM-rate gap left after P1.

## P7. V2 showed no threshold shift

**Fix.** V2 now sweeps 2–240 Hz at two inhibition levels, with desynchronised SOM, and
measures the rate where ρ crosses 0.5.

**Result** (`figures/validation_vs_papers/results.json`): the LTP threshold is
- **12 Hz** on the free branch;
- **98 Hz** with SOM at 15 Hz;
- **> 240 Hz** with SOM at 30 Hz.

Inhibition shifts the LTP threshold to higher rates, as Yang Fig 7b shows. V3 at 80 Hz:
free 0.925, inhibited 0.227, ratio 4.1.

## P8. The soma could not influence plasticity

**Problem.** bAPs came from an independent Poisson source, Yang's pinned-rate protocol.
So the MD→PV → soma arm could not reach learning.

**Fix.** `context_circuit(bap_source='soma', soma_drive_hz, soma_drive_nS)`. With the
soma driven at about 7 Hz (100 × 10 Hz × 0.2 nS), its own spikes are the bAPs.

**Test** (`experiments/bap_soma_coupling_test.py`, `docs/audit/bap_soma_coupling.json`):
- **Gating works with somatic bAPs:** free 0.922, gated 0.209.
- **The PV arm is effectively off.** At realistic MD→PV (×0–×6), PV is at about 0 Hz,
  held down by SOM→PV inhibition from the active SOM channel. It switches on abruptly
  only at ×20 (188 Hz). Then it silences the soma and slightly reduces LTD on the gated
  branch (0.21 → 0.27).
- **V4 was missing SOM→PV.** That wire is present in every canonical builder. With it
  added, V4 shows PV at 0 Hz until MD silences SOM (MD ≥ 20 Hz), then 45–116 Hz. PV's
  response to MD comes from SOM releasing it, not from MD→PV drive.

**Open calibration issue.** The MD→PV arm is ineffective against SOM→PV in the
canonical parameters.

## P8 follow-up — PV calibration (2026-11-02)

**Input side: done and applied.** The PV background (`weight_bg_pv` 0.25 nS) was tuned
before SOM→PV existed. `gGABA_pv` = 2 nS then shunted PV completely: about 9.6 nS mean,
roughly 10× its leak. Yang leaves SOM→PV strength free (Fig. 6b) and states PV "never
reaches zero". I swept the two knobs jointly (`experiments/pv_calibration.py`, seeds 42–44,
MD→PV p/n/g untouched) against targets set before running:
- T1: baseline 5–10 Hz;
- T2: graded MD response, ≥ 3× by MD 40 Hz;
- T3: SOM silenced releases PV, ≤ 60 Hz.

The passing ridge is (0.28, 0.03), (0.29, 0.05), (0.30, 0.05) nS. Chosen: its centre,
**`weight_bg_pv` = 0.29 nS, `gGABA_pv` = 0.05 nS**.
- PV runs 7 → 11 → 18 → 39 → 63 → 94 Hz over MD 0–40 Hz with SOM active, and 20 Hz with
  SOM silenced.
- Caveat: the ridge is narrow (PV fires on input fluctuations), so treat the two values
  as a pair.

Verified (`docs/audit/pv_calibration_verify.json`):
- `tests/test_pv_arm.py`: 10/10.
- V4: PV 6.2 → 144 Hz, graded, where it was 0 before SOM shut off.
- Gating unchanged: full circuit 20/20 seeds at 30 Hz, same ρ ranges.
- Retention unchanged: "both" 100%, inhibition-only 35–40%, seeds 42–44.
- PV now fires 46–50 Hz inside an MD context.

**Output side (PV→soma): open, needs a modelling decision.** With PV active,
`gGABA_pv2soma` = 5 nS silences a driven soma outright. A grid over 0.25–5 nS × somatic
drive 0.2–0.5 nS (`experiments/pv_soma_calibration.py`) never meets the targets: soma
5–15 Hz in context, and divisive rather than silencing. Even at 0.25 nS the soma goes
74 → 16 → 0 Hz over MD→PV ×0/×1/×3. The soma is a threshold LIF on mean-driven input, so
over PV's ~30× range (7 → 220 Hz) inhibition is switch-like. Graded, Yang-like somatic
inhibition would need a fluctuation-driven (balanced E/I) somatic drive. This does **not**
affect any canonical result: the canonical bAPs come from a Poisson source, so somatic rate
cannot reach plasticity. `gGABA_pv2soma` is left at 5 nS.
